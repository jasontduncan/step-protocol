# WorkTree bootstrap provenance

This directory preserves the historical WorkNode that directed development of the early Node.js/TypeScript WorkTree implementation.

`PLAN.md`, `STATE.md`, and `logs/` are retained as execution evidence. Their original terminology and path references describe the repository at the time the work was performed. They are provenance, not additions to the STEP protocol and not the repository's current self-node.

The generated implementation remains available in the repository history.
