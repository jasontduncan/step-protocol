# STEP RFCs

STEP Requests for Comments make protocol evolution conspicuous and reviewable.
They are proposals, not protocol authority.

| RFC | Title | Status |
| --- | --- | --- |
| [0001](0001-step-core-hardening.md) | STEP Core hardening from production evidence | Draft |

An RFC becomes normative only when a later change incorporates accepted
semantics into `PROTOCOL.md` and records the associated compatibility decision.
