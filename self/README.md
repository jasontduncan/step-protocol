# STEP used on STEP

This directory preserves the WorkNode artifacts used to build and prepare the early STEP implementation and public repository.

The plan, state, and logs are evidence of the protocol in use. They are historical artifacts, not the current protocol specification. Some entries retain the earlier names `WorkTree` and `docs/work/`; those names describe the repository layout and terminology at the time of execution.

The generated Node.js/TypeScript CLI is not included in the current tree. It remains available in the repository's earlier commits. The durable artifact here is the structured intent and execution record that directed its creation.
